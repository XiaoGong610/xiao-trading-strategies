# Knowledge Base

Reference docs for investment decision-making. Skills consult these for context and nuance.

## Structure

```
knowledge/
  signals/         — How to interpret technical and options signals
    rsi-guide.md         RSI thresholds, sector beta context, common mistakes
    iv-rank-guide.md     IV Rank × RSI decision matrix for strategy selection
    ma-guide.md          SMA alignment, entry levels, bullish/bearish stacks
    volume-guide.md      Volume confirmation, relative volume thresholds
    macd-guide.md        MACD divergences, signal interpretation

  frameworks/      — Reusable mental models and analytical frameworks
    ai-capital-flow.md   9-track AI supply chain bottleneck progression
    valuation.md         Forward P/E benchmarks by sector, CAPE/Shiller
    crypto-cycles.md     Bitcoin 4-year halving cycle, on-chain indicators
    sector-momentum.md   Mansfield RS, Weinstein Stage, momentum classification

  sectors/         — Sector-specific logic, metrics, cycle dynamics
    semiconductors.md    Sub-sectors, cycle signals, Qual cycle, AI overlay

  strategies/      — When to use each strategy, rules, edge cases
    when-to-csp.md       IV thresholds, delta/DTE selection, management rules
    when-to-leaps.md     IV environment, delta selection, vega risk, capital efficiency
    execution-framework.md  Order types (limit/market/scaled/DCA), stop placement,
                            exit strategies, ATR-based spacing, position sizing

  reference/       — Pointers to external resources and people
    influencers.md       High-signal X/Twitter accounts for research
    thetagang-leaders.md ThetaGang.com top traders reference
```

## How to Use

- Skills reference these files when making recommendations
- `/plan-stock` consults signals + strategies + execution framework
- `/research-stock` consults signals + frameworks + sectors
- `/portfolio-review` consults frameworks for risk assessment
- Updated as we learn and refine our thinking
- Not stock-specific — general principles that apply across stocks
